# PNG 砂金项目台

巴布亚新几内亚（Morobe 省，莱城 / Wau / Bulolo 一带）砂金项目的研究与工作台。家族项目，个人研究，不代表任何公司。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 项目台网页源码（2026-10-29 版本，含复核修正与可信度标注） |
| `calc-test.js` / `calc-expected.json` | 计算公式测试：27 个独立手算样例，全部通过 |
| `data-backup-2026-10-29.json` | 项目台录入数据的备份 |

## 在线版本

- 研究底稿《巴布亚新几内亚砂金矿研究》：https://claude.ai/artifact/D5AiZRD7ZpZec9UF3bbTCD（可下载为 Word / PDF / Markdown）

> `index.html` 直接用浏览器打开只能**离线浏览**：知识页面、换算器、盈利模型都能用，但录入数据、上传照片、照片识别、问 Claude 只在 claude.ai 的在线版本里可用。
>
> 研究底稿写于项目台之前；之后的复核修正（环保许可分级、总理承诺日期、IPA 保留行业清单等）以项目台为准。

## 核查情况（2026-10-29）

- **来源**：所有数字来自实际打开的网页或文件，页面"来源"页列出 75 个出处。
- **独立复核**：另一个复核助手逐条对照原文，发现并修正 4 处实质错误、11 处引用或表述问题。
- **计算测试**：品位（坑尺寸 / 淘盘 / 松方）、单位换算、五种土地主分成方案、盈亏平衡品位、热力图、现金流均与手算结果一致。
- **仍未核实**：PNG 砂金成色、砂金租约的权利金依据、AML 年租、CEPA 与 ICA 收费、实际办证时长、莱城设备租价与海运费、进口关税、雨季停工天数。
- **必须由专业人士确认**：合作结构合法性（PNG 律师）、矿点租约状态（MRA Wau 办事处）、取样与品位（持证地质师）、成色（化验室）。
